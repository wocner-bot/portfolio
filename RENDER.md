# Публикация WOCNERG на Render

Проект готов к размещению как Render Static Site. Публикуется папка `dist`:
главная, шесть отдельных кейсов, изображения, макеты телефонов и фоновое видео.
Файлы HTML уже созданы; установка зависимостей и сервер не нужны.

## Через Blueprint

1. Поместить проект в GitHub-репозиторий. Репозиторий может быть приватным; Render должен иметь доступ к нему.
2. В Render выбрать **New → Blueprint**, подключить этот репозиторий и ветку `main`.
3. Использовать `render.yaml` из корня проекта и создать сервис.
4. Дождаться успешного деплоя и открыть выданный адрес `onrender.com`.

Если в аккаунте уже существует сервис `wocnerg-portfolio`, перед созданием Blueprint нужно проверить, тот ли это сайт: Render может применить конфигурацию к одноимённому сервису.

## Настройки при ручном создании Static Site

| Поле | Значение |
| --- | --- |
| Name | `wocnerg-portfolio` |
| Branch | `main` |
| Root Directory | оставить пустым |
| Build Command | `test -f dist/index.html` |
| Publish Directory | `dist` |

Секреты, API-ключи, база данных и платный вычислительный сервер для сайта не нужны.
Не добавлять общий SPA rewrite на `/index.html`: у кейсов собственные HTML-файлы.

## Проверка после публикации

Открыть главную и `/work/atom/`, `/work/beeline-b2b/`, `/work/national-parking/`,
`/work/beeline-marketing/`, `/work/beeline-pricing/`, `/work/cargo-monitoring/`.
Проверить видео, ссылки на оригинальные изображения и Telegram/LinkedIn.

## Обновления

Содержимое главной находится в `dist/index.html`, общие стили — в `dist/style.css`.
Кейсы собираются командой `python3 build-cases.py`; затем нужно закоммитить обновлённые файлы в `dist`.
После подключения репозитория Render может автоматически публиковать изменения выбранной ветки.

Текущий сайт на ChatGPT Sites продолжит работать. Перенос собственного домена требует отдельного подключения домена в Render и изменения DNS.
